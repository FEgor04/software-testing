# Тестирование сайта "Ангелы Света" (Angely Sveta)

## Описание сайта
Сайт "Ангелы Света" (Angely Sveta), расположенный по адресу http://angely-sveta.ru/russian/default_ru.htm, представляет собой духовный ресурс, посвященный контактам с "вселенскими людьми" и "Силами Света". На основании мета-тегов сайта, он содержит контент, связанный с внеземными цивилизациями, духовностью, медитацией, НЛО и космическими учениями.

Сайт использует фреймовую структуру для навигации и, предположительно, содержит несколько языковых версий (основная рассматриваемая версия — русская).

## Сценарии использования

### Общий путь пользователя
1. Доступ к домашней странице и навигация по основным разделам
2. Переключение между языковыми версиями (если доступны)
3. Чтение статей и духовного контента
4. Просмотр изображений/медиа (если доступны)
5. Доступ к контактной информации

### Конкретные сценарии использования
1. **Навигация по домашней странице** — Пользователь посещает домашнюю страницу и получает доступ к главному меню
2. **Просмотр контента** — Пользователь может читать статьи и духовный контент
3. **Просмотр медиа** — Пользователь может просматривать изображения, видео или другие медиа
4. **Переключение языков** — Пользователь может переключаться между языковыми версиями
5. **Контактная информация** — Пользователь может найти контактные данные или форму обратной связи

## Чек-лист тестирования

### Функциональное тестирование
- [ ] Проверка корректной работы всех ссылок и элементов навигации
- [ ] Проверка правильной загрузки фреймов в поддерживаемых браузерах
- [ ] Проверка на наличие неработающих ссылок или ошибок 404
- [ ] Тестирование функциональности переключения языков (если доступно)
- [ ] Проверка правильной загрузки всех медиа (изображений, видео)
- [ ] Тестирование форм на корректность отправки

### Тестирование совместимости
- [ ] Тестирование в различных браузерах (Chrome, Firefox, Safari)
- [ ] Тестирование на различных устройствах (десктоп, мобильные, планшеты)
- [ ] Проверка резервного содержимого для браузеров, не поддерживающих фреймы

### Тестирование производительности
- [ ] Измерение времени загрузки страниц
- [ ] Проверка эффективности загрузки ресурсов
- [ ] Тестирование производительности сайта на медленных соединениях

### Тестирование контента
- [ ] Проверка читабельности и правильного форматирования текстового содержимого
- [ ] Проверка качества и релевантности изображений
- [ ] Обеспечение единообразия стилей на всех страницах

### Тестирование доступности
- [ ] Тестирование навигации с клавиатуры
- [ ] Проверка цветового контраста для удобочитаемости
- [ ] Тестирование совместимости со скринридерами

### Тестирование безопасности
- [ ] Проверка наличия защищенных соединений (HTTPS)
- [ ] Тестирование на наличие открытой конфиденциальной информации
- [ ] Сканирование на наличие распространенных уязвимостей

## План автоматизированного тестирования
Наши автоматизированные тесты с использованием Playwright сосредоточены на:
1. Базовой навигации по сайту и доступности
2. Проверке контента на ключевых страницах
3. Тестировании адаптивного дизайна
4. Оценке производительности
5. Кросс-браузерной совместимости

## Структура проекта тестирования
```
tests/
├── homepage.test.ts    # Тесты домашней страницы
├── navigation.test.ts  # Тесты навигации
├── content.test.ts     # Тесты контента
├── performance.test.ts # Тесты производительности
├── compatibility.test.ts # Тесты совместимости
├── utils.ts            # Утилиты для тестирования
└── screenshots/        # Скриншоты, сделанные во время тестирования
```

## Запуск тестов

```bash
# Установка зависимостей
npm install

# Запуск всех тестов
npx playwright test

# Запуск с открытым браузером
npx playwright test --headed

# Запуск конкретного теста
npx playwright test tests/homepage.test.ts
```
