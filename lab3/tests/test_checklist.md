# Чеклист тестирования сайта angely-sveta.ru

## 1. Переключение языка на английский
- [ ] Проверить наличие и видимость флага Великобритании на странице
- [ ] Проверить, что флаг является кликабельным элементом
- [ ] Проверить корректность переадресации на английский сайт (https://universe-people.com)
- [ ] Проверить, что переадресация происходит без ошибок
- [ ] Проверить, что после переадресации страница корректно загружается

## 2. Переход на страницу "Условие соединения"
- [ ] Проверить наличие и видимость ссылки "Условие соединения"
- [ ] Проверить, что ссылка является кликабельной
- [ ] Проверить корректность перехода на страницу условий соединения

## 3. РАЗГОВОРЫ С НАЗИДАНИЕМ
- [ ] Проверить наличие и видимость ссылки "РАЗГОВОРЫ С НАЗИДАНИЕМ ОТ МОИХ ДРУЗЬЕЙ ИЗ ВСЕЛЕННОЙ"
- [ ] Проверить, что ссылка является кликабельной
- [ ] Проверить корректность перехода на страницу с разговорами
- [ ] Проверить, что страница с разговорами корректно загружается
