### UseCases

#### Переключение языка на английский

Акторы: Пользователь
Действия:
  1. Пользователь нажимает на флаг Великобритании
  2. Пользователь переадресовывается на английский сайт (`https://universe-people.com`)

#### Переход на страницу "Условие соединения"

Акторы: Пользователь
Действия:
  1. Пользователь нажимает на ссылку "Условие соединения"
  2. Пользователь переходит на соответствующую страницу

#### РАЗГОВОРЫ С НАЗИДАНИЕМ

Акторы: Пользователь
Действия:
  1. Пользователь нажимает на ссылку "РАЗГОВОРЫ С НАЗИДАНИЕМ ОТ МОИХ ДРУЗЬЕЙ ИЗ ВСЕЛЕННОЙ"
  2. Пользователь переходит на страницу с разговорами
